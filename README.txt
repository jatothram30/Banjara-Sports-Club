BANJARA SPORTS CLUB - ANDROID SOURCE STARTER

This ZIP contains a Capacitor Android starter project.
It builds a basic local cricket scoring prototype APK.

BUILD:
1. Upload the contents of this ZIP to the root of your GitHub repository.
2. Commit the files to the main branch.
3. Open GitHub -> Actions.
4. Run the workflow named "Build Android APK".
5. Download the artifact named "Banjara-Sports-Club-APK".
6. Extract it and install app-debug.apk on your Android phone.

IMPORTANT:
This is a starter/prototype. Scores are stored only in the running app session.
Cloud sync, accounts, admin/scorer approvals, public live score links, player profiles,
tournaments, full wagon wheel and complete scorecard/statistics need a backend and
additional development. This ZIP does not claim those features are complete.
